# Building Agent

This repository contains Azure infrastructure and sample applications for enterprise solutions.

## Contents

### Infrastructure
- **[infra/](infra/)** - Azure Container Apps Landing Zone (ACA LZA) infrastructure using Bicep and Azure Developer CLI

### Sample Applications (src/)
- **[auth-nodejs-quickstart/](src/auth-nodejs-quickstart/)** - Node.js backend with Microsoft Entra ID authentication and Cosmos DB
- **[auth-reactmsal-quickstart/](src/auth-reactmsal-quickstart/)** - Next.js frontend with MSAL authentication
- **[cosmos-db-nosql-nodejs-quickstart/](src/cosmos-db-nosql-nodejs-quickstart/)** - Cosmos DB NoSQL with Node.js/TypeScript
- **[app-config-nodejs-quickstart/](src/app-config-nodejs-quickstart/)** - Azure App Configuration with Key Vault integration
- **[storage-nodejs-quickstart/](src/storage-nodejs-quickstart/)** - Azure Blob Storage samples
